# Security policy

## Supported versions

Paper Amigo is pre-release software. Security fixes target the latest code on
`master` and the newest published release.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Report a vulnerability

Do not open a public issue or pull request for a suspected vulnerability.

Use GitHub's private vulnerability reporting feature in the repository Security
tab. If that feature is unavailable, contact a maintainer privately through the
contact details on their GitHub profile and ask for a secure reporting channel.

Include:

- The affected route, component, dependency, or commit.
- Steps to reproduce the issue.
- The likely effect and who can trigger it.
- Any proof of concept, logs, or suggested fix that can be shared safely.

Avoid accessing data that is not yours, disrupting service, or publishing the
issue before maintainers have had a reasonable chance to investigate and ship a
fix.

Maintainers should acknowledge a complete report within five business days and
provide a status update within ten business days. Timing for a fix depends on
severity and release risk.
